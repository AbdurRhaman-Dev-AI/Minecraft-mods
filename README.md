# Minecraft-mods

A collection of individual Minecraft mods. Each mod lives in its own folder with its source code, documentation, and compiled `.jar` file.

## Mods

| Mod | Minecraft / Loader | Version | Description | Download |

| [GodTech: Ascension](./GodTechAscension/README.md) | `1.21.1` / NeoForge (`21.1.267`) | `2.0.0` | Sci-fi endgame progression mod with Arc Reactors (`16,384 FE/t`), Alloy Synthesizer, Ascension Exosuit & Jetpack, Plasma Railgun, Warp Beacons, JEI category, and `Hold [W]` animated guides. | [godtechascension-2.0.0.jar](./GodTechAscension/godtechascension-2.0.0.jar) |
